# 규격 검증 기록

각 매체 규격(`*.yaml`)을 매체 공식 문서와 대조한 기록입니다. 검수 결과 화면에서 대조하지 않은 지면에는 "공식 문서 미대조" 표시가 붙습니다.

- `verification.status`: `verified`(전 지면 대조) / `partial`(일부) / `unverified`(대조 전)
- 지면별 `verified: true`와 `source`(근거 페이지)가 있어야 대조 완료로 봅니다.
- `unstated`: 공식 문서에 값이 없는 항목. 값을 지어내지 않고 비워 두거나, 쓴 값의 근거를 `description`에 적습니다.
- `source_type`: `official_page`(현행 공식 웹페이지, 기준일 = 조회일) / `official_document`(공식 PDF 등, 기준일 = 문서 작성일) / `media_confirmed`(매체 직접 확인, 기준일 = 확인일).
- **최신성 원칙**: 공식 문서라도 기준일이 12개월보다 오래됐으면 그 값만으로 판정을 바꾸지 않고 `needs_confirmation: true`(결과에 "매체 확인 중")로 둡니다. 근거: 네이버 타임보드 가이드(2023-04)는 200KB였지만 매체 확인 결과 현행 300KB.
